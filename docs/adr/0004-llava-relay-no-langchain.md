# LLaVA relay agents (HF transformers, no LangChain), Korean via translation step, empty Qdrant case store

Phase 2's 4-agent relay (DefectDescriber → RootCauseAnalyzer → SeverityClassifier → RecipeAdvisor) had three open questions in Plans.md: whether RootCauseAnalyzer needs real/simulated telemetry, which narrative LLM to use, and whether case search (Qdrant) is needed. Resolved as follows. RootCauseAnalyzer reasons from the Stage 1 defect class plus general fab-process domain knowledge only — no telemetry dependency, so Phase 3 (equipment logs) is not a prerequisite and Phase 2 can proceed standalone. All four agents run on a single model, LLaVA (`llava-hf`, loaded directly via `transformers`, matching how `DinoV2Classifier` already loads DINOv2 in this repo), chosen because SemiFA — the reference architecture for this project — uses LLaVA; this repo has no cloud API keys configured anywhere and a sibling project (`langgraph_chatbot`) already runs local Ollama models on this same GB10 box, so a local VLM keeps that pattern. Only DefectDescriber takes the rendered wafer-map image as input; RootCauseAnalyzer/SeverityClassifier/RecipeAdvisor are text-only, chained on DefectDescriber's output. LLaVA is Vicuna/Mistral-based and reasons better in English than Korean, so each agent generates in English and a final translation pass through `exaone3.5:7.8b` (Ollama, already pulled locally, Korean-specialized) produces the Korean text actually shown in Streamlit. Nodes call `transformers`/Ollama directly — no LangChain — since the relay is a fixed 4-step sequential chain with no tool-binding or prompt-composition needs LangChain would help with; only `langgraph` is added as a dependency. RecipeAdvisor gets a Qdrant collection (`wafer_defect_cases`, `nomic-embed-text` embeddings — already pulled locally, and Qdrant is already running for other projects on this box) with working retrieval logic, but the collection starts empty: case grounding is functional infrastructure now, backfilling actual case data is deferred backlog, not a Phase 2 blocker.
