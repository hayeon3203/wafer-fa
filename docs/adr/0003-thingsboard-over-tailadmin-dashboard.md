# ThingsBoard instead of TailAdmin for the Stage 2.5 demo dashboard

The original Stage 2.5 plan called for a TailAdmin (React+Tailwind) template calling a FastAPI wrapper. We're switching to ThingsBoard instead. ThingsBoard is an IoT platform built around real-time device telemetry ingestion and widget-based dashboards (heatmaps, trend charts, threshold sliders) — the exact shape of the reference dashboard the user wants (lot selection, composite wafer-map heatmaps, per-pattern lot trend, model-threshold scoring). TailAdmin would need all of that built as custom React components; ThingsBoard ships it as configurable widgets. This also sets up a natural path into Stage 3 (equipment log correlation via the Digital Twin Feed concept in CONTEXT.md), since ThingsBoard's core purpose is device/telemetry dashboards — Stage 2.5 and Stage 3 can now live on the same platform instead of bolting an analytics panel onto a generic admin template.
